# TAMARU NAAM - Developer Portfolio

A responsive personal portfolio showcasing my MERN stack projects, skills and contact links.

🔗 **Live Demo:** https://USERNAME.github.io/portfolio

## ✨ Features

- Mobile-first responsive layout (Flexbox + CSS Grid)
- Dark / Light theme toggle (saved in localStorage)
- Smooth scrolling navigation
- Mobile hamburger menu
- Auto-scrolling roles marquee slider (React, Node.js, Full Stack)
- Featured project cards with modal popups
- Skills grid
- Resume download and contact links
